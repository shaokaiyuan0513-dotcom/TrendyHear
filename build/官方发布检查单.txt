Publish checklist (full text: docs/PUBLISHING.md). Run top to bottom; stop at HUMAN.

  B=<app>/bundle
  1. tools/octo doctor                                  # hub + card-host found
  2. Edit $B/manifest.json: id, name, version (new for every release),
     only the capabilities the app uses, every host in network.hosts
  3. Edit $B/listing.json: every placeholder (publisher, support,
     privacy_policy_url https, description, category, platforms you TESTED)
  4. tools/octo run $B --port 8141 --detach             # admitted line printed
  5. Test every interaction natively: curl -s 127.0.0.1:8141/snap,
     /click?x=&y=, /t?t=TEXT, /k?k=down&c=ReturnKey ... (docs/QUICKSTART.md)
  6. tools/octo shot 8141 $B/screenshots/01-main.png    # LOOK at the PNG
     curl -s 127.0.0.1:8141/quit
  7. tools/octo check $B                                # stamps, then gate: PASSED
  8. hub scan $B --packet build/review.json             # answer its questions
  9. HUMAN: create/hold the publisher key outside the repo
       hub keygen /secure/path/publisher.key   (once)
       hub sign-manifest $B --key /secure/path/publisher.key --key-id <publisher-id>
       hub check $B --publisher-key <publisher-id>=$(hub pubkey /secure/path/publisher.key)
     Any edit after signing: restamp and sign again.
 10. HUMAN: tag the commit and open an issue "Submit <id> <version>" on
     OctoSense-org/OctoSense-App-Hub (docs/PUBLISHING.md 3.8). Never edit its
     catalog.json/index/artifacts. Never claim it was submitted or approved
     unless a person did it.

# 操作、结果和失败状态

版本：skystream.trendyhear 0.4.3（已签名；catalog sequence 11）
源码：`bundle/`（main.splash + manifest.json + listing.json + AGENT.md + screenshots/）

## 1. 三步卡片收集偏好（当前交互）

1. 打开 TrendyHear → 点「**听见顾问**」
2. 应用依次推送三张固定模板卡片：
   - ① 第 1/3 步：选择兴趣主题（最多三个，选择顺序即优先级；可自定义主题）
   - ② 第 2/3 步：选择阅读目的（若干选项，可「跳过」）
   - ③ 第 3/3 步：选择推送时间（若干时点，或「按需阅读」）
3. 每张卡片的选择写回 `accounts/device/pref-answer.json`，应用校验后进入下一步
4. 三步选完 → 写入 `accounts/device/state.json` → 立即抓取 RSS → 语义筛选 ≤8 条 → 生成 100–200 字今日简报

## 2. 实际运行路径

官方 `hub` 对包签名 → 本机签名目录 → OctoSense shell 的 App Hub Get / Install / Open → 原生 Splash 应用 →
`host.request("glance.publish")` 发卡片 → 卡片按钮 `fs.write` 写回执 → 应用 `accept()` 落盘 →
`net.http_request` 抓真实 RSS → `host.request("model.complete")` 整理与撰写简报。

## 3. 已验证

- 包准入（gate）：**`— PASSED`**
- 无头启动：admitted + 首帧绘制 + 运行日志无错误
- 真实 Shell：三步卡片交互、保存偏好、抓取新闻、生成简报（此前已跑通，产出 8 条新闻与简报）

## 4. 暂未验证 / 已知限制

- 模型调用曾因**服务商侧 HTTP 529（集群负载高）**失败；已把该应用的每日 token 覆盖限额调高，重试即可。
- **应用读不到「Ask <app>」面板里的自由输入**（shell 按 instance 隔离 person lane），因此偏好收集不经过该面板。
- **当前版本未调用 agent**（manifest 保留 `agent.profile=read-only`、`tools=[ask_user_question]`）。
- 语音、后台定时、自动追问、英文翻译、语义去重仍暂缓。

## 5. 怎么复现

1. App Hub → TrendyHear → Remove（若已装旧版）→ GET 安装 0.4.3
2. 打开应用 → 点「听见顾问」→ 按三张卡片依次选择
3. 点「确认保存」→ 观察应用抓取 RSS 并生成简报
4. 核对 `accounts/device/state.json` 的 `prefs` 与 `articles`
